# Lobby & Recruitment System

The Lobby system is a core feature designed to help players find groups for various activities and organize recruitment for specialized sessions.

## Key Features
- **Dynamic Grouping**: Post a lobby with specific requirements and let others join with a single click.
- **Automated Coordination**: Once a session starts, the bot provides a dedicated space for the group.
- **Staff Oversight**: Server staff can manage active lobbies to ensure they follow guidelines.

## Commands

### Prefix Commands
- `,host`: Initiates the creation of a recruitment or carry lobby (opens a detailed setup form).
- `,lfg`: Quick setup for a standard "Looking For Group" or grind-style lobby.

## User Interface
- **Join Button**: Allows other users to claim a slot in your lobby instantly.
- **Start Button**: Once filled, the host can start the session to begin the group activity.
- **Cancel Button**: Allows the host or staff to close the lobby at any time.

## Workflow
1. **Creation**: A host sets up a session via an easy-to-use interface.
2. **Recruitment**: Other users view the post and join the available slots.
3. **Execution**: The host starts the session, and the group receives a private space for coordination.
