# General Utilities

The General module provides a suite of features aimed at improving daily user interaction and providing community statistics.

## Key Features
- **Community Leaderboards**: Track the most active and reputable users within your server or across the bot's network.
- **Server Discovery**: View information about the communities where the bot is active.
- **Detailed Profiles**: Comprehensive user summaries showcasing reputation and activity stats.

## Commands

### Slash Commands
- `/leaderboard`: Displays the top vouchers and reputable members in the current server.
- `/lbservers`: Shows a global ranking of the most active servers using MistBot.
- `/profile [user]`: Shows a detailed reputation profile for yourself or a specified user.
- `/ping`: Checks the bot's current connection latency.
- `/servers`: Lists the servers where MistBot is currently present (paginated for easy browsing).
- `/secret`: A fun command that fetches a random Muichiro Tokito GIF.
