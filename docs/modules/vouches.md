# Vouching system

## Overview
The Vouching system is a reputation management tool that allows users to endorse each carrier for positive carrying experiences. It serves as a trust-building mechanism within the community.

## Key Features
- **Reputation Tracking**: Each carrier has a vouch count that reflects their standing in the community.
- **Manual Management**: Staff members can manually adjust vouch counts to maintain accuracy.
- **Profile Integration**: Vouch counts are displayed on user profiles for easy reference.

## Commands
- `,vouch [user]`: Vouches a user for a positive carrying experience.

### Staff Commands
- `/addvouch [user] [amount]`: Manually adds a specific number of vouches to a user's profile.
- `/removevouch [user] [amount]`: Manually removes a specific number of vouches from a user's profile.
- `/resetvouches [user]`: Completely resets a user's vouch count to zero.

## Usage
Staff members can use these commands to reward positive behavior or correct any inaccuracies in the vouch system. The changes are reflected immediately on the user's profile.
