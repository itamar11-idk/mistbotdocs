# Help System

The Help module provides a user-friendly guide to all of MistBot's features, organized logically for easy navigation.

## Key Features
- **Smart Navigation**: Uses an interactive menu to categorize commands by their purpose.
- **Auto-Discovery**: Automatically recognizes available features based on the user's permissions and the server's configuration.

## Commands
- `/help`: Opens the primary interactive help menu, allowing you to browse different categories and view detailed command descriptions.

## How to Use
- Simply use the help command to open a navigable menu showing all accessible features tailored to your current permissions.
