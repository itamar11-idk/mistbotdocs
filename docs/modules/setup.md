# Configuration Wizard

The Configuration Wizard is a user-friendly tool that guides server owners through setting up MistBot without any technical knowledge.

## Key Features
- **Interactive Walkthrough**: A multi-step menu that guides you through naming channels and roles.
- **Automated setup**: Handles the creation of necessary spaces and permissions automatically.

## Commands
- `/setup-mist`: Launches the full interactive setup wizard. (Strictly restricted to Server Administrators).

## Setup Steps
- **Marketplace**: Connect your server to the global trade network.
- **Lobbies**: Organize your gaming recruitment categories.
- **Values**: Enable or disable the item value commands.
- **Security**: Choose where to receive global scam alerts.
- **General**: Configure staff roles and logging channels.
