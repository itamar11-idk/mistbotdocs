# Message Linking System

This system bridges live chat with the marketplace by identifying trade intent automatically and suggesting market posts.

## Key Features
- **Auto-Detection**: Monitors trading channels for possible trade offers.
- **Smart Suggestions**: Privately prompts users to post their trades to the global marketplace when intent is detected.
- **User Control**: Full ability to verify, edit, or ignore automated suggestions.

## User Benefit
- Automates the process of getting trade offers onto the global market.
- Increases listing accuracy by suggesting structured data based on chat history.
